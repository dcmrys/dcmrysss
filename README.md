# CounterFlow POS

A small CodeIgniter 4 point-of-sale demonstration with landing, About,
Customer Accounts, and User Accounts pages. The account data is intentionally
stored in static PHP arrays, so the application does not require a database.

## Deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/dcmrys/dcmrysss)

The Render Blueprint builds the application with PHP 8.2 and Apache, installs
production Composer dependencies, enables the required PHP extensions, and
serves the CodeIgniter `public` directory.

## Local URL

With Apache running in the bundled XAMPP location, open:

`http://localhost/dcmrysss/demonstration_ci4/demonstration_ci4/`
